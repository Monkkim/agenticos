# Long-Term Memory

비즈니스에 대한 **장기 지식**을 축적하는 문서. 세션별 단기 기억(`memory/YYYY-MM-DD.md`)과는 다르다.

## 사용 방법

- 이 파일은 여러 세션에 걸쳐 유지되는 **변하지 않는 사실**을 담는다.
- 새로운 장기 사실이 확정되면 해당 섹션에 append. 구식이 된 정보는 제거.
- `ops/wrap-up` 실행 시 하루에 발견된 "반복적으로 유효한 사실"을 여기로 승격할지 판단.
