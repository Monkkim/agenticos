# youtube-audit

데이븐포트 채널의 성과 데이터를 분석해 **이 채널만의 우수 패턴**(훅 / 주제 / 길이 / CTA)을 추출하고, 다음 영상 5편의 추천 주제와 훅 공식을 만든다. `script-scoring`이 이 결과를 채점 기준으로 사용한다.

---

## 언제 실행되는가

- 사용자가 "채널 감사" / "유튜브 분석" / "채널 데이터 봐줘" 발화
- "최근 30일 / 90일 영상 분석" 요청
- `script-scoring` 실행 직전에 최신 audit이 없으면 사용자에게 추천

---

## 실행 절차

### 0단계 — 의존성 Read (병렬)

- `brand-context/voice.md`
- `brand-context/icp.md`
- `brand-context/positioning.md`
- `brand-context/samples.md`
- `context/learnings.md`의 `strategy/youtube-audit` 섹션
- (있으면) `output/analysis/` 하위 가장 최근 audit.md — 시계열 비교용

### 1단계 — 데이터 입력 수집

확보 우선순위:
1. 사용자가 CSV 파일 경로 제시 → Read
2. 사용자가 영상 리스트 채팅 paste (제목 / 조회수 / 길이 / 게시일 최소 4컬럼)
3. 사용자가 스크린샷만 첨부 → "영상 제목·조회수·길이를 텍스트로 paste 해주실 수 있을까요?" 1회 확인

최소 데이터 요건:
- **영상 10편 이상** (10편 미만이면 "감사 결과는 directional, 정밀 채점 불가" 명시)
- 컬럼: 제목 / 조회수 / 영상 길이 / (선택) CTR / 평균 시청 시간 / 게시일

### 2단계 — 평균·분포 계산

- **채널 평균 조회수** = sum(조회수) / count(영상)
- **우수 분류**: 조회수 ≥ 평균 × 2배
- **저성과 분류**: 조회수 ≤ 평균 × 0.5배
- 평균 영상 길이 / CTR 평균 (있으면) 계산

10편 미만 또는 분산이 너무 큼(중간값과 평균 차이 50% 이상): "데이터 분산 큼, 결론은 directional" 헤더 명시.

### 3단계 — 우수 패턴 추출

우수 영상 묶음에서 다음 패턴 식별:
- **훅 구조** — 제목 첫 단어, 키워드, 구조(질문형 / 단언형 / 대조형 / 명령형 / 비교형)
- **주제 카테고리** — Claude Code / n8n / 보이스 에이전트 / AI 자동화 / 기타
- **영상 길이 sweet spot** — 우수 영상 길이 분포의 중간값 ± 표준편차
- **(있으면) 썸네일 패턴** — 사용자가 별도 설명한 경우만
- **CTA 유형** — 영상 끝 CTA를 사용자가 메모해 두면 분석 가능

### 4단계 — 저성과 안티패턴 추출

저성과 묶음에서:
- 우수에 없는 주제 / 길이 / 훅 형식
- "왜 안 됐는지" 가설 (제목·길이·게시 시간 관점에서)

### 5단계 — 다음 5편 추천

`positioning.md`의 시그니처 주제(보이스 에이전트, Claude Code 실전)와 우수 패턴을 결합:
- 추천 주제 5개
- 각 주제에 어울리는 훅 공식 1개씩 (제목 템플릿)
- "이 채널만의 훅 공식" 3~5개 (이 채널 데이터에서 반복적으로 작동한 형식)

### 6단계 — 산출물 작성

`output/analysis/$(date +%F)-channel-audit/audit.md` 작성. 골격:

```markdown
# 채널 감사 — YYYY-MM-DD

## 요약 (3줄)
- 분석 영상: N편 / 채널 평균: X회 / 우수: M편 / 저성과: K편
- 우수 키워드: ...
- 다음 5편 추천 키워드: ...

## 우수 패턴 Top 5
1. ...
2. ...

## 회피 패턴 Top 3
1. ...
2. ...

## 이 채널만의 훅 공식
- 공식 A: [구조] → 예시 제목
- 공식 B: ...

## 다음 영상 5편 추천
| # | 주제 | 추천 훅 | 길이 | 비고 |
|---|---|---|---|---|

## 데이터 신뢰도
- 영상 수: N편 (≥10편: 정밀 / <10편: directional)
- 분산: 적정 / 큼

## 원자료 요약
| 영상 | 조회수 | 평균대비 | 길이 | 분류 |
|---|---|---|---|---|
```

### 7단계 — 사용자 검토 안내

3줄 보고:
```
✓ 채널 감사 완료 — output/analysis/<날짜>-channel-audit/audit.md
✓ 우수 N편 / 저성과 K편 / 다음 5편 추천 포함
→ script-scoring을 돌릴 때 이 audit이 자동 참조됩니다
```

### 마지막 단계 — 학습 로깅

피드백 있으면 `context/learnings.md`의 `strategy/youtube-audit` 섹션 append.

## 입력
- 영상 리스트(제목 / 조회수 / 길이 최소) — CSV 또는 paste
- (선택) CTR / 시청 시간 / 게시일 / 썸네일 메모

## 출력
- `output/analysis/$(date +%F)-channel-audit/audit.md`

## 의존성
- `brand-context/voice.md` / `icp.md` / `positioning.md` / `samples.md`
- `context/learnings.md`

## 중요 원칙
- **데이터 양에 따른 신뢰도 명시**: 10편 미만이면 directional만 제공.
- **추측 패턴은 명시**: "썸네일 빨강이 우세" 같은 패턴은 사용자가 썸네일 정보를 제공한 경우만 추출.
- **외부 벤치마크 금지**: 이 채널 데이터로만 판단. "유튜브 평균 ~"같은 일반 통계 끌어오지 않음.
- **다음 5편 추천은 positioning + 우수 패턴 교집합**: 시그니처 주제 우선.
