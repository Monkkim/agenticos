# Personal Brand Question Bank

개인 브랜드 / 지식 창업 도메인 (뉴스레터·강의·SNS·코칭). `common.md`와 함께 로드.

## 전문 분야

1. **어떤 주제의 전문가로 알려지고 싶은가?** (한 단어 ~ 한 문장)
2. **그 주제에 대해 얼마나 깊이 알고 있나?** (현업 경험 연차 / 자가 학습 / 자격증 / 실적)
3. **왜 하필 이 주제?** (개인 스토리 한 줄)

## 주 채널

4. **주력 플랫폼은?** (뉴스레터 / 블로그 / 유튜브 / 인스타 / 링크드인 / X)
5. **보조 채널?** (복수 선택)
6. **현재 팔로워/구독자 규모?**

## 콘텐츠 유형

7. **주로 만드는 콘텐츠 형태?** (에세이 / 튜토리얼 / 리뷰 / 인터뷰 / 뉴스 큐레이션 / 오리지널 연구)
8. **1콘텐츠당 평균 제작 시간?** (<1시간 / 1~3시간 / 3~8시간 / 하루 이상)

## 수익/전환 구조

9. **지금 수익 모델?** (유료 구독 / 강의 / 코칭 / 책 / 제휴 / 스폰서 / 본업 보조)
10. **궁극적으로 가고 싶은 수익 구조?**

## 포지션
