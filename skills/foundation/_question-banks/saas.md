## 제품

1. **제품을 한 문장으로?** (목적 + 기능, 25자 이내)
2. **출시 단계?** (프리런치 / 베타 / 정식 런칭 / PMF 도달 / 스케일업)
3. **유료 고객 수?** (0 / <10 / 10~100 / 100~1000 / 1000+)
4. **MRR/ARR 규모?** (공개 가능 범위)

6. **사용자 (User) 직함?** (구매자와 같음 / 다름 — 다르면 명시)
7. **회사 규모?** (스타트업 / SMB / 미드마켓 / 엔터프라이즈)
