# Common Question Bank

**모든 도메인 공통 질문**. `start-here`가 어떤 도메인을 선택하든 이 질문지는 항상 먼저 로드한다.

## 사용 규칙

- 한 번에 하나씩 묻는다.
- 가능하면 AskUserQuestion의 선택지 형태로.
- 사용자가 "모르겠다"고 하면 `(미입력)` 마커로 기록하고 다음 질문으로.

---

## 브랜드 기본

1. **프로젝트/브랜드 이름은?** (아직 없으면 "아직 없음"도 OK)
2. **얼마나 오래 이 일을 해왔나요?** (선택지: <6개월 / 6~12개월 / 1~2년 / 2~5년 / 5년+)
3. **주 수익/성과 모델은?** (선택지: 광고 / 구독 / 판매 / 프리랜스 / 취미 / 아직 없음)

## 톤 & 스타일

4. **평소 글 쓸 때 존댓말/반말?** (존댓말 / 반말 / 섞어 씀)
5. **공식적인가, 친근한가?** (슬라이더: 1=공식 ↔ 5=친근 사이)
6. **자주 쓰는 추임새·감탄사 있나요?** (예: "결국", "솔직히", "아니 근데")
7. **절대 쓰기 싫은 표현은?** (예: "대박", "꿀팁", "혁신적")

## 타깃 오디언스

8. **이 사람들은 주로 몇 살대인가요?** (10대 / 20대 / 30대 / 40대+ / 혼합)
9. **그 사람들은 어디에서 나를 처음 만나나요?** (유튜브 / 인스타 / X / 링크드인 / 검색 / 지인 추천)
10. **그 사람들이 해결하고 싶어하는 가장 큰 문제 한 가지는?**

## 경쟁 / 차별점

11. **이 분야에서 나 말고 참고하는 사람/서비스 2~3개 말해주세요.**
12. **그들과 다르게 하고 싶은 한 가지는?**

## 금기

13. **법적/윤리적/브랜드적으로 절대 하면 안 되는 건?** (예: 특정 키워드 사용 금지, 특정 업계 언급 금지)

## 작업 선호

14. **나에게 제안을 줄 때 선호하는 선택지 개수?** (2개 / 3개 / 4개)
15. **작업 완료 후 보고 방식?** (한 줄 요약 / 불릿 3개 / 표 / 상세 설명)
