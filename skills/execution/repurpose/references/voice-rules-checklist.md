# Voice 규칙 자체 검증 체크리스트 v0.1

> **용도**: `repurpose` skill 4단계에서 산출물을 1행씩 통과시키는 체크리스트.
> 위반 항목이 1개라도 ❌면 즉시 재작성한다.
> 출처: `brand-context/voice.md` / `icp.md` / `positioning.md` / `assets.md`의 규칙을 운영용으로 모은 사본.

---

## 모든 플랫폼 공통

### 금지어 (voice.md / samples.md / assets.md)
- [ ] `딸깍` / `딸깍 한 번` 미포함
- [ ] `월천만원` / `월1000` / `월 천만원` 미포함
- [ ] `대박` 미포함
- [ ] `꿀팁` 미포함
- [ ] `혁신적` / `혁신` 미포함 (단순 명사로도)
- [ ] `게임체인저` 미포함
- [ ] `누구나` 미포함
- [ ] `여러분 모두` 미포함
- [ ] `~해보시면 됩니다` 미포함
- [ ] `~라고 할 수 있습니다` 최소화

### 후킹 / 어그로
- [ ] 첫 줄에 `충격` / `실화` / `놓치면 후회` 미포함
- [ ] 느낌표 남발(2회 초과) 없음
- [ ] 이모티콘 어그로(`🚨` / `❗`) 없음

### 톤
- [ ] 존댓말 (`~해요` / `~습니다` 혼용) — 기본 `~해요`, 결론·선언에서 `~습니다`
- [ ] 1인칭 ("저는" / "제가") 우세
- [ ] "여러분" 남발 없음 (한 산출물에 1회 이하)
- [ ] 톤 수치 2/5 — 비즈니스 문서보다 편하지만 친구톤은 아님

### 구체성
- [ ] 모호 표현(`많은` / `엄청` / `정말`) 대신 숫자·도구명 명시
- [ ] 외부 인물·사례 인용 시 인물명 명시 (가능하면 출처 링크)

### Positioning Not-For 영역 (positioning.md)
- [ ] "AI 하나로 쉽게 돈 버는 법" 약속 없음
- [ ] "10분만에" / "5분만에" 비현실적 시간 약속 없음
- [ ] 노코드 만능론 없음
- [ ] 엔터프라이즈 컨설팅 어조 없음

### CTA (assets.md)
- [ ] CTA가 허용 목록 안 (`뉴스레터에서 계속` / `유튜브에 실제 화면 녹화` / `링크는 프로필에`)
- [ ] 금지 CTA 없음 (`지금 바로 신청!!` / `놓치면 후회` / `딸깍 한 번이면`)
- [ ] CTA는 1개 (복수 CTA로 시선 분산 ❌)

## 인스타 / 쓰레드 전용

- [ ] **본문 마지막 문장 끝 마침표(`.`) 생략** ← 핵심 규칙 (voice.md)
- [ ] 첫 125자(인스타) / 1번 게시물 500자 이내(쓰레드) 안에 훅 완성
- [ ] 한 단락 2~5줄, 단락 사이 빈 줄
- [ ] 인스타: 해시태그 본문 안에 ❌ — 별도 섹션
- [ ] 인스타: 해시태그 3~5개 (10개 이상 ❌)
- [ ] 쓰레드: 게시물 사이 `---` 구분
- [ ] 쓰레드: 1번 게시물이 단독으로도 의미 통함
- [ ] 쓰레드 마지막 게시물에 CTA + 다음 채널 안내 1줄

---

## 숏폼 훅 전용

- [ ] 각 훅 10단어 이내 (한국어 6~10어절)
- [ ] 도구명이 첫 줄(첫 어절~3어절 내)에 등장
- [ ] 도입어(`안녕하세요` / `오늘은` / `지금부터`) 미사용
- [ ] 시청자가 행동 가능한 형태 (`내가 ~할 수 있겠다`)
- [ ] 3개 훅이 서로 다른 각도(결과 / 대조 / 도구) 다룸 — 다양성 확보
- [ ] (캡션을 붙였다면) 캡션도 한 줄 이내

## 뉴스레터 (옵션 ON일 때만)

- [ ] 마침표 사용 (SNS와 반대) — 단, 한 줄 강조 라인은 예외 가능
- [ ] `$%name%$님` 5~10회 등장 (스티비 변수 보존, 임의 치환 ❌)
- [ ] 서명 고정: `$%name%$님의 AI 디렉터` 줄바꿈 `- 투쏠 드림 -`
- [ ] 12블록 골격 따름 (제목 / 인사+근황 / 주제도입 / 외부인용 / 사례풀이 / 핵심인용 / 본인적용 / 호명+질문 / 추가인사이트(선택) / 호명+행동제안 / 마무리 / 공지(선택) / 클로징+서명)
- [ ] 분량 1500~3500자

## 자기 검증 흐름

1. 위 항목을 위에서 아래로 순서대로 체크
2. 1개라도 ❌ 나오면 해당 부분 즉시 재작성
3. 전부 ✅ 되면 `4단계` 통과
4. 통과 후 사용자에게 "검증 완료" 1줄 보고 (장황한 보고 ❌)

## 운영 메모

- 이 체크리스트는 voice.md / icp.md / positioning.md / assets.md의 규칙을 1곳에 모아 둔 운영용 사본.
