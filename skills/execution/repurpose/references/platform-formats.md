## 인스타그램 (릴스 영상 대본)

> **2026-05-09 갱신**: 사용자 본인 인스타 운영 = 릴스 영상. 피드 캡션이 아니라 **영상 발화 대본**으로 작성한다. (이전 v0.1 피드 캡션 가정은 폐기)

### 분량 / 호흡 (⚠️ 절대 룰)
- **전체 텍스트 200~280자** (한국어 공백 포함) — 250자 넘기면 릴스 호흡 깨짐
- **발화 시간 30~45초**
- **한 줄 = 한 호흡** (줄바꿈으로 박자 만듦, 한 줄 6~15자 권장)
- 단락 = 의미 묶음. 단락 사이 빈 줄로 휴지.
- 첫 1~2줄 안에 후킹 완성 (1.5초 안에 손가락 멈추게)
- **한 영상 = 한 인사이트**. 다중 인사이트(격리/메가/시스템 등)는 시리즈로 분할.

### 구조
1. **후킹 1~2줄** — 후킹 공식 5종(`brand-context/voice.md` 릴스 대본 모드 참조)
   - `[도구]인데 [용도]입니다`
   - `또 누군가 깃허브에 뿌렸습니다`
   - `여러분 ~ 정말 ~죠?`
   - `~믿으시겠습니까? 됩니다 시작`
   - `제가 ~ 질려죽겠다 / 반드시 ~ 사용할 겁니다`
2. **도구 한 줄 설명** — 무엇을 해주는 스킬·도구인지 한 호흡으로
3. **사용법 단계 (4단 표준)**
   - `DM/링크 클릭` → `skill MD 다운로드` → `클로드에 넣기` → `슬래시 커맨드 한 번`
   - 단계마다 줄바꿈, "끝입니다 / 끝납니다"로 종결
4. **클로징 한 줄** — `이게 진짜 요물인 게 ~ / 정말 편하겠죠? / 장난 아니던데 / 심지어 ~까지` 중 1
5. **CTA 한 줄** — 다음 4종 중 1
   - 댓글 이벤트형: `사용해보고 싶으시다고요? 댓글에 [숫자] 라고 남겨주세요`
   - DM 자동발송: `DM으로 발송되는 링크를 클릭`
   - 시청 유지: `어떻게 만들었는지 궁금하시다면 [N]초만 집중해주세요`
   - 채널 유도: `자세한 셋업은 뉴스레터에서 이어가요` (`assets.md` 허용 CTA)
6. **본문 마지막 문장 마침표 생략** ← voice.md 핵심 규칙
7. **해시태그 3~5개** — 별도 섹션 `## 해시태그` (첫 댓글용)

### 톤
- 1인칭 ("저는" / "제가") — 의지 선언형 OK
- 본인 표현 적극 차용: `이것도 요물입니다` / `이게 진짜 요물인 게` / `심지어` / `이야 진짜` / `장난 아니던데` / `굉장히 편하겠죠?`
- 어그로 첫 줄 금지 (`충격` / `놓치면 후회` / `실화` / `🚨`)
- 본문 중간 마침표는 호흡 우선으로 자유 생략

### 예시 (실제 본인 대본 패턴)

```
클로드 코드인데 PM입니다

또 누군가 깃허브에 뿌렸습니다

댓글을 남기면 발송되는 PM 스킬인데
이것도 요물입니다

말 그대로 회사의 PM업무를 대신 해주는 스킬입니다

아이디어 탐색, 전략 방향, PRD, 지표설정 등등
PM이 할법한 그런 일들을 누군가 Skill로 만들었습니다

원하는 스킬만 골라서 다운로드 후 사용하거나
클로드 코드에 해당 링크로 PM직원을 만들어줘 라고 할 수 있겠습니다

이야 진짜 마케터에 이어 PM
그리고 클로드 디자인까지

DM으로 발송되는 링크를 받아보세요
```

## 쓰레드 (Threads, @meta)

### 분량
- 1번 게시물: 500자 이내(공식 한도). 단독으로도 의미가 통해야 함.
- 2~5번: 한 게시물 1 아이디어. 자유롭지만 짧을수록 잇기 좋음.
- 총 게시물 3~6개

### 구조
- **1번 — 훅** (단독으로 흥미)
  - 형식: 대조 / 단언 / 짧은 질문 중 1
  - 예: "n8n 메인이었던 사람이 Claude Code로 갈아탄 이유"
- **2~5번 — 잇기**
  - 1 게시물 = 1 포인트
  - 게시물 사이 `---` 구분 (이 파일에선 마크다운 구분선이지만, 실제 게시 시엔 새 게시물로 따로 올림)
- **마지막 — CTA** (1줄, 다음 채널 안내)

### 톤
- 인스타보다 캐주얼·대화형
- 짧게 끊어 치는 리듬
- 친근 마커(`ㅎㅎ` / `ㅠㅠ` / `:)`) 가끔 OK
- **각 게시물 본문 마지막 마침표 생략**

### 예시
```
1번:
n8n 메인이었던 제가 Claude Code로 갈아탄 이유

작년 1년 내내 노드 그리던 사람의 결론

---

2번:
n8n은 그래픽 워크플로 시각화가 강점이에요

근데 LLM 호출이 80%인 흐름에선 시각화가 오히려 부담이 됨

---

3번:
Claude Code는 텍스트 위주

대신 슬래시 커맨드 하나로 동일 흐름이 정리됨

작업 시간 3시간 → 25분

---

4번:
지금까지 옮긴 흐름 6개

전부 화면 녹화 떠서 유튜브에 올려놨어요

링크는 프로필에
```

## 숏폼 훅 (Shorts / Reels / TikTok)

### 분량
- 한 훅 10단어 이내 (한국어 어절 기준 6~10어절)
- 발화 시 2~4초

### 구조 / 공식
`[도구명] + [내가 ~한다]` 또는 `[도구명] + [구체 결과]`

### 규칙
- **첫 줄에 도구명 노출** (예: "Claude Code", "보이스 에이전트")
- 시청자가 자기 모습을 그릴 수 있는 형태 ("내가 ~할 수 있겠다")
- 금지 시작어: `안녕하세요` / `오늘은` / `여러분` / `지금부터`
- 금지 표현: `충격` / `놓치면 후회` / `딸깍` / `월천만원`
- 멋진 표현보다 **시청자 행동 가능성** 우선

### 좋은 예시 3개
1. "Claude Code 하나로 n8n 흐름 다 옮겼어요"
2. "보이스 에이전트로 고객 통화 자동 응답"
3. "유튜브 1개 넣으면 인스타·쓰레드 자동 생성"

### 나쁜 예시 (쓰지 말 것)
- "AI로 인생 역전!" (어그로)
- "오늘은 Claude Code에 대해 이야기해볼게요" (도입어 낭비)
- "딸깍 한 번에 자동화 끝" (금지어)

### 캡션 (선택)
훅 아래 한 줄 캡션을 붙여도 됨. 문맥 보강용.
- 예시:
  - 훅: "Claude Code 하나로 n8n 흐름 다 옮겼어요"
  - 캡션: "├ 슬래시 커맨드 하나로 노드 12개 대체"

### 산출물 템플릿 (shorts-hooks.md)
```markdown

> 출처 영상: <YouTube URL>

## 훅 A (각도: 결과)
<10단어 이내>
캡션(선택): <한 줄>

## 훅 B (각도: 대조)
<10단어 이내>
캡션(선택): <한 줄>

## 훅 C (각도: 도구)
<10단어 이내>
캡션(선택): <한 줄>
```

## 산출물 폴더 구조

```
output/repurpose/$(date +%F)-<topic>/
├── instagram.md       # 인스타 피드 캡션 (해시태그 별도 섹션)
├── threads.md         # 쓰레드 멀티포스트 (게시물별 --- 구분)
└── shorts-hooks.md    # 숏폼 훅 3개 (각 캡션 옵션)
```

뉴스레터 옵션 ON일 때만 추가:
```
output/newsletter/$(date +%F)-<topic>/
└── newsletter.md      # 12블록 (script-to-newsletter 패턴 위임)
```
