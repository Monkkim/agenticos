# 데이븐포트(투쏠) 뉴스레터 패턴 v0.1

> **추출 일자**: 2026-04-30
> **출처**: 사용자가 직접 공유한 발송 뉴스레터 6편 (2025–2026)
> **용도**: `script-to-newsletter` skill이 본문 작성 시 골격 레퍼런스로 사용.

---

## 표준 골격 (12블록)

### 1. 제목 (Subject)

후킹/어그로 ❌. 본론·질문·단언 중 하나.

| 유형 | 예시 |
|---|---|
| 명령형 | "시스템부터 만들지 마세요" |
| 대조형 | "AI는 신기한걸 팔면 안돼요, 대신 이걸 팔아야 하죠" |
| 회고 질문형 | "올 한해 어떤 성장을 이루셨나요?" |
| 비교 질문형 | "안티그래비티 VS 클로드 뭘 써야 할까?" |
| 단언형 | "앞으로 10년, 빠르게 달리는 것만이 답이 아닙니다" |

작성 규칙:
- 35자 이내 권장
- 느낌표·이모티콘·"🚨" 금지
- "충격/실화/대박/딸깍/월천만원" 금지
- 본문 핵심을 한 문장으로 압축한다는 감각

### 2. 인사 + 근황 (1~2문장)

```
안녕하세요 $%name%$님 [근황 한 줄]
[본인 근황 한 줄]
```

자주 쓰는 패턴:
- "오랜만에 레터를 드리네요 잘 지내셨나요?"
- "지난 한 주 잘 보내셨나요?"
- "좋은 목요일입니다 (늦어서 죄송합니다.. ㅠㅠ)"
- "크리스마스는 잘 보내셨나요?"

본인 근황은 살짝 자기 노출 — "정신없는 2주", "개발하랴 촬영하랴 정신이 없네요 ㅎㅎ".

### 3. 오늘의 주제 도입 (1~3문단)

본인의 최근 고민/관찰을 솔직하게 풀어놓고, 오늘 다룰 주제를 예고.

전형 패턴:
- "저는 요즘 ~한 강박(?)이 느껴지기도 했습니다"
- "이렇게 정신이 없는 와중에 하나 좋은 내용을 발견하였는데요"
- "오늘은 ~에 대한 이야기를 한번 드려볼까합니다"

### 4. 외부 사례 / 소스 인용

- 인물명 + 맥락 (1줄): "Hilary Gridley라는 사람의 인터뷰 봤습니다"
- 발견 경로 자주 명시: "이번 주에 발견한 한 사례", "Startup Ideas 팟캐스트에 나와서"
- 출처 링크는 가능할 때 명시 (Substack/유튜브):
  ```
  📺 출처: [How to prepare for the next decade — Scott Barker](URL)
  ```

자주 등장한 영감원: Hilary Gridley, Dan Koe, Scott Barker, Alex Hormozi, Epidemic Sound CEO, Chris(AI 에이전시) — **영어권 사례를 한국 맥락으로 번안**.

### 5. 사례 풀이 (5~8개 짧은 섹션)

- 한 단락 2~5줄
- 단락 사이 빈 줄로 호흡
- 핵심 문장은 한 줄로 분리하여 강조
- 짧고 단언적인 문장 선호

```
그녀의 일과는 이런 식이에요

아이디어가 떠오르면 폰 뒷면을 두 번 탭해서 받아쓰기로 한마디 던지고 끝냅니다

AI도 없고 자동화도 없습니다. 그냥 아이폰 기본 기능이에요
```

### 6. 핵심 인용 (큰따옴표)

- 외부 인물의 강한 발언 1~3개를 큰따옴표로 묶기
- 인용 직후 본인 반응 1줄: "이 말에 뜨끔했습니다"

### 7. 본인 적용 / 1인칭 경험

- "저도 ~한데요"
- "사실 이건 남의 이야기가 아닙니다 제 이야기예요"
- 도구 변천사 자주 활용: "작년에 저는 n8n에 빠져서…"
- 시그니처 주제: 보이스 에이전트, Claude Code 실전, CS/CRM

### 8. $%name%$님 호명 + 질문 #1 (본문 중간)

본문 흐름 중간에 한 번 호출:
```
$%name%$님은 어떠신가요?

$%name%$님의 일주일에서
10배 잘하면 10배 임팩트 나는 일은 뭔가요?
```

### 9. 추가 인사이트 (옵션, 1~3문단)

첫 사례를 심화하거나 두 번째 작은 사례를 붙임. 길이 부족 시 생략 가능.

### 10. $%name%$님 호명 + 행동 제안

이번 주 액션 1~2개. 번호 매기기(`하나`, `둘`).

```
이번주에 함께 이걸 같이 해보면 어떨까요?

하나, 본인 채널에서 역대 가장 반응이 좋았던 콘텐츠 3개를 골라보세요...

둘, 그 가이드를 들고 이번 주 콘텐츠 1개를 직접 써보세요...
```

### 11. 마무리 — 현재 포커스

본인이 현재 집중하는 1~3개를 글머리 기호로:
```
제가 요즘 집중하고 있는건 이겁니다

- 하루의 시스템화
- Context 주입 및 관리
- 불안과 두려움의 역행
```

다음 주 예고 한 줄:
- "다음주에는 한번 더 좋은 내용으로 뉴스레터를 들고 와 보도록 하겠습니다"
- "그럼 다음주 뉴스레터에서 뵙겠습니다!"

### 12. (옵션) 공지 / CTA

본문 흐름과 자연스럽게 연결되는 경우만:
- 새 유튜브 영상 안내
- 강의 런칭 + 쿠폰 코드
- 보이스 에이전트 무료 시연 제안 ("부담 없이 이메일로 답장을 한번 보내주세요")
- 톤: 자랑·강매 ❌ / 솔직·동료 ⭕

### 13. 클로징 + 서명 (고정 — 절대 변경 금지)

```
[클로징 한 줄: "한주 잘 보내세요:)" / "남은 한 주도 화이팅입니다!" 등]

감사합니다
$%name%$님의 AI 디렉터
- 투쏠 드림 -
```

## 스타일 디테일

### 문장
- **존댓말 `~해요` / `~습니다` 혼용** — 기본 `~해요`, 결론·선언에서 `~습니다`
- **마침표 사용** — voice.md의 SNS 마침표 생략 규칙은 **뉴스레터엔 적용 안 됨** ⚠️
- 단, 한 줄로 떨어진 강조 라인은 마침표 없이 끝나기도 함
- 평균 30~50자 단문

### 단락
- **빈 줄 자주, 적극적으로**
- 한 단락 2~5줄
- 강조 라인은 한 줄로 분리

### 톤 마커
- 친근 이모티콘: `:)` / `ㅎㅎ` / `ㅋㅋ` / `ㅠㅠ` — 가끔, 진솔할 때
- 자기 비하 농담: "(저는.... 하루종일 일을 했지만요... ㅠㅠ)"
- 단언형 핵심: "결국 핵심은 이겁니다"

### 강조
- 큰따옴표 — 외부 인물 발언 인용
- 한 줄 단문 — 자체 강조
- 글머리 `-` — 정리·리스트
- `**굵게**` — 제목/구획 분리에만, 본문은 자제

## 자주 등장하는 모티프 (재사용 가능)

- 시스템 / 자동화 — 본인 정체성 영역

- 보이스 에이전트 — 시그니처 사업
- 속도 vs 본질 — 반복되는 철학적 갈등
- 결과 vs 도구 — "AI 비즈니스의 80%는 AI가 아니다"
