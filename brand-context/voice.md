## 한 줄 톤 요약

> **AI 실전을 담백하게 전달하는 전문가 동료** — 과장·어그로 없이, 직접 해본 사람의 구체성만.

## 말투 3가지 키워드

- `담백한` — 후킹·클릭베이트 없이 본론 직행
- `실전적인` — 이론보다 직접 굴려본 결과/사례 중심
- `과장-없는` — "대박·혁신·딸깍" 제로, 숫자와 구체로 말함

## 문장 스타일

- **존댓말** — `~습니다` / `~해요` 섞어 씀 (기본 `~해요`, 결론·선언에서는 `~습니다`)
- **톤 수치**: 2/5 (약간 공식) — 비즈니스 문서보다는 편하지만, 친구톤까지는 아님
- **평균 문장 길이**: 30~50자 선호. 짧은 문장으로 리듬.
- **1인칭 선호**: "저는" / "제가" — "여러분" 남발 지양
- **구두점**: 말줄임표(`…`)·느낌표(`!`)는 최소. 대신 `—`로 호흡 끊기.
- **🚨 SNS 본문 마침표 규칙**: 인스타·쓰레드·피드 본문의 **마지막 문장 끝 마침표(`.`) 생략**. (사용자 명시 선호, 2026-04-21)
- **숫자 사용**: 구독자·팔로워·시간·금액 같은 구체 수치를 선호 (모호한 "많은" 대신 "1만 명")
- **선호 구조**: **번호 매긴 단문 리스트** — 긴 글을 17개짜리 번호 리스트로 쪼개는 호라이즌프레스 스타일 차용. 스크롤 피로 제거 + 리듬감.

## 자주 쓰는 표현

_(2026-05-09 본인 인스타 릴스 대본 7편에서 추출)_

**감탄·평가**
- `이것도 요물입니다` / `이게 진짜 요물인 게`
- `이야 진짜 ~`
- `장난 아니던데`
- `정말 편하겠죠? / 굉장히 편하겠죠?`

**연결·강조**
- `심지어 ~까지 가능한데`
- `또 누군가 깃허브에 뿌렸습니다` (외부 도구 도입어)
- `그런데 제약이 있는데 뭐냐면..` (cliffhanger)

**1인칭 의지 선언**
- `저는 이 스킬을 반드시 사용할겁니다`
- `제가 ~ 질려죽겠다`
- `프롬프트가 아닙니다`

**종결**
- `끝입니다 / 끝납니다`
- `됩니다 시작`

**사용법 4단 표준**
- `[링크 클릭] → [skill MD 다운로드] → [클로드에 넣기] → [슬래시 커맨드 한 번]`

## 릴스 영상 대본 모드 (인스타 산출물 기본)

본인 인스타 운영 = 릴스 영상 대본. 피드 캡션이 아니라 **영상 발화 대본**으로 작성한다.

- **분량 200~280자, 발화 30~45초** ⚠️ 절대 룰. 넘기면 호흡 깨짐.
- **한 줄 = 한 호흡** — 줄바꿈으로 박자를 만든다. 한 줄 6~15자 권장.
- **한 영상 = 한 인사이트** — 다중 인사이트는 시리즈로 분할.
- **본문 중간 마침표 자주 생략** — 호흡 단위 우선. 마지막 문장은 반드시 생략.
- **후킹 공식 5종** (samples.md 참조): `[도구]인데 [용도]입니다` / `또 누군가 깃허브에 뿌렸습니다` / `여러분 ~ 정말 ~죠?` / `~믿으시겠습니까? 됩니다 시작` / `제가 ~ 질려죽겠다`
- **클로징 3종** — Cliffhanger(`~ 그런데` / `심지어 ~까지 가능한데` / `그런데 제약이 있는데 뭐냐면..`) · CTA 직접형(`댓글에 [숫자]`) · 공감형(`정말 편하겠죠?` / `장난 아니던데` / `이게 진짜 요물인 게 ~`)
- **CTA**: 댓글 이벤트형 · DM 발송형 · 시청 유지형(`[N]초만 집중해주세요`) · 채널 유도형(`뉴스레터에서 계속`) 중 1

## 금지어 / 피해야 할 표현

**절대 금지 (사용자 명시)**
- `과한 후킹` — "충격! / 실화? / 놓치면 후회" 같은 어그로 제목
- `딸깍` — "딸깍 한 번에", "딸깍 월천만원", "~만 누르면" 계열
- `월천만원 / 월1000` 같은 수익 과장 키워드 단독 사용

**일반 금지 (AI 클리셰)**
- `대박` / `꿀팁` / `혁신적` / `게임체인저`
- `~해보시면 됩니다` (책임 회피형)
- `여러분 모두` (과장 일반화)
- `~라고 할 수 있습니다` (모호한 완충)

## 샘플 (Before → After)

**Before (일반 AI 문장 / 어그로 스타일):**
> "AI로 월 천만원 버는 꿀팁 대공개! 누구나 딸깍 한 번이면 자동화 사업가가 될 수 있습니다. 지금 바로 확인해보세요!"

**After (데이븐포트 voice):**
> "Claude Code로 자동화 에이전트를 만들어 팔아봤어요. 작년엔 n8n이 메인이었는데, 지금은 거의 Claude Code 하나로 정리됩니다. 어떤 게 바뀌었고, 뭘 먼저 배워야 하는지 정리했습니다."

**차이점:**
- 후킹·과장 제거 → 결과와 맥락 먼저
- 숫자 모호함("월천만원") 제거 → 구체 도구명("Claude Code")
- "누구나/딸깍" 제거 → 본인 경험 1인칭
