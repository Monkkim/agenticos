# Positioning

> **상태**: ✅ v0.1 (2026-04-21 초기 설정) — 실제 제안서/랜딩 카피에 써보며 계속 다듬기

데이븐포트가 **누구인지, 무엇이 다른지**를 정의한 문서. 자기소개·랜딩 카피·제안서·피치덱의 공통 재료.

## 한 줄 포지셔닝

**최종 확정본 (v0.1, 사용자 최종 선택 전까지는 후보 병기):**

> **"한국어로 AI 실전을 따라붙을 수 있게 만드는 1인 AI 크리에이터."**

### 후보 3개 (필요 시 교체 가능)

1. **공식형 (March 포뮬러)**
   > "AI 흐름에 적응하고 싶은 30~40대 실무자를 위해, '딸깍 월천만원' 마케팅 대신 직접 해본 실전 결과를 한국어로 전달하는 1인 AI 크리에이터."

2. **친근형 (구어체)**
   > "AI, 한 번쯤 제대로 써보고 싶은 분들을 위한 한국어 실전 가이드. 저도 작년까지 n8n 쓰다가 Claude Code로 갈아탔어요."

3. **도발형 (짧고 대조)**
   > "번역체 AI 과장 콘텐츠 말고, 직접 해본 한국어 실전."

## 카테고리 (Frame of Reference)

- **AI 실전 크리에이터 / 1인 AI 비즈니스 에듀케이터**
- 하위 맥락: AI 자동화 · AI 에이전트 · 보이스 에이전트 · Claude Code 실전

## 타깃 (For Whom)

`icp.md` 요약:

> **AI 흐름에 적응하고 싶지만 어디서부터 시작해야 할지 모르는 30~40대 실무자**. 본업이 있거나 1인 사업자로, 한국 맥락에 맞는 실전 가이드를 찾고 있음. "딸깍 월천" 과장 마케팅은 이미 의심하고 있음.

## 핵심 편익 (Key Benefit)

- **"나도 AI 흐름에 따라붙을 수 있겠다"는 자신감과 첫 실행 경험.**
  - 추상적 AI 담론이 아니라 → 바로 따라할 수 있는 한국어 단계별 가이드
  - 어그로 후킹 없이 → 실측 수치·실전 도구 변천사로 설득
  - 특히 **보이스 에이전트**와 **Claude Code 실전**은 한국어권에서 구체적 가이드가 드문 영역

## 증거 (Why Believe)

- **실 채널 규모** (2026-04 기준)
  - 유튜브 **10,000명**
  - 인스타그램 **5,400명**
  - 쓰레드 **6,000명**
  - 뉴스레터 **3,000명**
- **도구 변천사 자체가 증거**: 2025년까지 n8n 기반 자동화 → 현재 Claude Code 메인으로 전환. "해보고 바꿨다"의 실사례.
- **시그니처 주제**: 보이스 에이전트 / Claude Code 실전 — 한국어 콘텐츠 시장에서 희소성 있음.

| **Nick Saraev, Nate Herk 등 미국 AI 유튜버** | 한국어 · 한국 맥락 · 한국 실무자 시나리오. 번역·적응 부담 제거. |

## 하면 안 되는 것 (Not-For)

명시적으로 타깃하지 않는 유형:

- **"AI 하나로 쉽게 돈 버는 법"** 만 원하는 사람 — 후킹에만 반응, 실전 따라할 의지 없음.
- **클릭베이트·과장 콘텐츠**를 선호하는 오디언스.
- **엔터프라이즈 AI 컨설팅**을 원하는 기업 담당자 — 지금은 B2B 포지션 아님.
- **완전 비기술자가 "노코드로 10분만에 끝내는" 약속**을 원하는 사람 — 현실적 난이도 안내 필요.
