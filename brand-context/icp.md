# ICP — Ideal Customer Profile

> **상태**: ✅ v0.1 (2026-04-21 초기 설정) — 실제 DM/댓글/후기 3개 이상 확보 시 voice-of-customer 섹션 갱신

데이븐포트의 **핵심 독자·고객 한 명**을 정의한 문서. 모든 execution skill(copywriting / ugc-scripts 등)이 이 페르소나를 머릿속에 놓고 작성한다.

---

## 주 페르소나

- **이름 (가상)**: "준호" (또는 "소현")
- **나이대 / 직군**: 30~40대, 직장인·실무자 중심 (일부 프리랜서·1인 사업자 포함)
- **하루 일과 한 줄**: 본업을 하면서 출퇴근·점심·저녁 틈틈이 "요즘 AI 이거 뭐지?"를 검색하다 인스타·유튜브·쓰레드에서 데이븐포트를 만남.

## 해결하려는 문제 (Pain)

- **"AI에 관심은 있는데 어디서부터 시작해야 할지 모르겠다."** — 정보가 넘치지만 파편화돼 있고, 순서가 안 보임.
- **"나만 뒤처지는 것 아닌가"** 라는 조용한 불안. 주변이 다 AI 얘기하는데 본인은 ChatGPT 몇 번 써본 게 전부.
- **구체적 액션이 없음** — 튜토리얼을 봐도 "내 상황에 어떻게 쓰지?"로 이어지지 않음.
- **업계의 과장·사기성 마케팅 때문에 진짜 쓸만한 정보를 골라내기 힘듦.**

## 현재 시도 중인 방법 / 대안

- **미국 AI 유튜버들(Nick Saraev, Nate Herk 등)** 영상 시청 → 영어·문화 차이로 완전 체화 어려움
- **ChatGPT 가끔 사용** — 쓰기·요약 정도까지만
- **무료 강의·블로그 글 찾아 읽기** → 맥락 없이 파편 지식만 쌓임
- **"월천만원 AI 자동화" 광고** 자주 접하지만 의심과 불신 동시 — 속으로 "이게 진짜일까"

## 원하는 변화 (Desired Outcome)

- **"AI 흐름에 내 속도로 따라붙을 수 있겠다"는 자신감** — 거창한 스타트업이 아니어도, 본인 일에 AI를 붙여 시간을 줄이거나 새 수익을 실험할 수 있다는 감각.
- **첫 번째 작은 성공 경험** — "이 주제로 자동화 하나 돌려봤다 / Claude Code로 이거 짜봤다"를 스스로 말할 수 있게 되는 것.
- **한국어·한국 맥락의 실전 가이드** — 본인이 바로 따라할 수 있는 수준의 구체성.

## 결정 트리거

이 사람이 "이거다" 하고 반응하는 순간:
- **데이븐포트 본인의 실측 결과**를 보여줄 때 ("구독자 N명 확보", "이 흐름으로 바꿨더니 X시간 아낌")
- **특정 도구의 실전 비교**("작년 n8n → 지금 Claude Code로 정리된 이유") — 도구 변천사 자체가 공감 포인트
- **구체적 단계**가 영상/글에 포함되어 있을 때 (추상론이 아니라 "1. 이걸 설치 → 2. 이 명령어")
- **"저도 여기서 막혔었어요"** 같은 동료 포지션의 진솔함

## 반감 포인트 (Turn-offs)

_(사용자는 명시하지 않았지만, voice.md의 금지어와 일관되게 추정 — 실제 데이터 확보 시 교체)_

- **"딸깍 월천만원"** 계열 어그로 카피
- **과장된 성공 서사** (아무것도 없던 사람이 하루 만에 대박)
- **한국 맥락 없는 번역체 용어 나열** ("워크플로우를 옵티마이즈합니다")
- **전문가 연기** — 본인이 직접 해보지 않은 것을 자신 있게 설명하는 톤
- **팔이·판촉 일변도 콘텐츠** — 교육 없이 상품만 파는 느낌

## 자주 쓰는 채널 / 미디어 소비

- **인스타그램** — 릴스/피드로 짧게 요약된 인사이트
- **유튜브** — 5~15분 튜토리얼/리뷰 선호
- **쓰레드** — 텍스트 기반 짧은 인사이트/대화
- **뉴스레터** — 출근길·점심 읽기용 긴 호흡 콘텐츠
- 영어 AI 크리에이터(Nick Saraev, Nate Herk 등) 콘텐츠도 함께 소비

## 실제 발화 예시 (voice-of-customer)

_(미입력 — 실제 DM/댓글/후기 수집 후 원문 그대로 3~5개 인용 권장)_

> (예시 템플릿) "AI 써보고 싶긴 한데 어디서부터 시작해야 할지 막막해요."

> (예시 템플릿) "한국어로 된 실전 자료가 진짜 없네요. 영상 도움 많이 됐습니다."
